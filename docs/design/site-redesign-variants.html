Android companion

The pond, in your pocket

Follow your agents while you're away from the desk, answer their questions, dictate a prompt, open the PC's terminals, files and browser tabs.

  1. Install the APK — Flowcode-Android-<version>.apk, allow unknown sources once.
  2. Turn on remote access — Settings → Agents → Allow access from the phone app. A QR code appears.
  3. Scan it — tap Add computer. That's it: no account, no VPN, no port forwarding.
🔒 Connected through iroh: end-to-end encrypted, peer-to-peer, relay only as fallback. Remote access is off by default; revoke a device any time. A paired device can type into your terminals.

Plugins

Extend it without risk

Plugins are declarative JSON — not code. Install a colleague's shortcut bar without wondering what it runs. Agents can even write plugins for you through the Flowcode MCP server, and you approve them from a chat card.

{
  "id": "deploy-staging",
  "name": "Deploy to staging",
  "icon": "rocket",
  "actions": [{
    "type": "run",
    "command": "npm run deploy -- --env staging",
    "confirm": "Deploy current branch?"
  }],
  "status": {
    "popup": "https://ci.example.com/badge.json",
    "refresh": 60
  }
}

Up and running in a minute

  1. Download the installer for your system.
  2. Run it. Already installed? It offers to update and keeps your settings.
  3. Pick a theme in the short first-run tour. Updates then arrive in-app, verified against signed checksums.
Requirements: Windows 10+, macOS 12+ (universal), Linux x86_64 with WebKitGTK 4.1. Agents are installed separately — Flowcode offers the install command for each one.

handbook / overview

A quiet pond for loud agents.

Flowcode is a desktop terminal that keeps your shells, files, browser and AI coding agents in one place — calm, light and native. This handbook is the whole tour.

⬇ Download v0.37.0Read the 2-minute tour →
Greetings from the pond — where the terminal is the center.

What's in the pond

Why it exists


fig. 1 — a dragonfly
between two tabs

Terminal, file manager, editor, a browser to check usage limits: four windows, and the thread lost every time you switch. Flowcode folds them into one — and puts the terminal back in the middle, with everything else following its folder.

Agents aren't "just another program": Flowcode recognises Claude Code, Codex, Gemini, Mistral Vibe, OpenCode and Cline, shows their state, their limits, their history — and lets you talk to them in a real chat when you'd rather not read a TUI.

handbook / getting started

Getting started

Five things to know, in the order you'll meet them.

1 · Open a tab

The + in the tab bar opens your default shell; right-click it to pick another (PowerShell, cmd, bash, zsh, WSL…).

2 · Let the panel follow you

The side explorer and Git dock follow the active tab's folder. cd somewhere and watch them come along.

3 · Start an agent

Type claude, codex or gemini in a tab. It appears in the agent panel with its usage gauge — or open a chat tab instead.

🐸 The frog on an empty tab isn't decoration: it surfaces while the agent starts and sinks into the pond when a session ends.

4 · Pick up where you left off

Tabs, folders and output return when you reopen the app. Settings survive updates.

5 · Bring your phone

Optional. See Phone app.

handbook / agents

Agents

Six agents, each with profiles, history and — where the provider exposes it — a usage gauge.

Several accounts per agent? Use profiles: each gets its own config folder, login and gauge, selectable from the agent's popup.

Delegation

Any agent can hand a task to another through the Flowcode MCP server: Claude plans, Codex writes the tests, both report back in the chat as a card you can open.

handbook / chat mode

Chat mode


fig. 2 — lily in bloom

The same agents, in a calm chat instead of a TUI. Flowcode talks to them through ACP.

⏱ Cache warning. For Claude, Flowcode reads the prompt-cache TTL from the transcript and warns you before it expires — keep it warm or let it go.
handbook / phone app

Phone app

An Android companion that mirrors your desktop: chats, terminals, files, browser tabs, dictation and three pixel-art home-screen widgets.

Pairing

Settings → Agents → Allow access from the phone app, then Add computer on the phone and scan the QR.

How it connects

Through iroh: end-to-end encrypted, peer-to-peer, relay as fallback. No account, no VPN.

Security. Remote access is off by default. A paired device can type into your terminals — revoke it any time from the same page.
handbook / plugins

Plugins

Declarative JSON manifests for the shortcuts bar and the Features menu. Nothing runs that isn't written in the file.

// ~/.flowcode/plugins/deploy.json
{ "id": "deploy-staging", "name": "Deploy to staging",
  "actions": [{ "type": "run", "command": "npm run deploy", "confirm": "Deploy?" }] }

The full schema lives in PLUGINS.md. The library shows installed, built-in and community plugins side by side.

handbook / mcp server

The Flowcode MCP server

Agents running inside Flowcode get a small set of tools to reach back into the app.

ToolWhat it does
delegate_taskHand a prompt to another agent, get the result back
open_in_browserOpen a URL or local file in the in-app browser panel
call_userRing you with a bubble when the agent needs you
list_agentsSee which agents are installed and signed in
plugin toolsCreate, edit or remove plugins — each one needs your consent

handbook / faq

FAQ

Is it free?

Yes, Apache 2.0. You bring your own agent subscriptions or API keys.

Why not Electron?

Tauri uses the system webview: a smaller install, faster start, less memory.

Does my code leave my machine?

Only through the agents you run. The phone link is end-to-end encrypted; dictation runs locally with Whisper.

iOS app?

Not yet — Android only for now.

Why a frog?

Flow → stream → pond. And >_ looks like a smile.
