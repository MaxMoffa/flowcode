Cosa apre il drawer

La stessa regola vale per le tre varianti, e anche per i link toccati nel terminale.

EventoOggiProposta
Link a localhost, 127.0.0.1, 0.0.0.0, [::1] con portaFoglio del link, poi browser del telefono, dove quel server non esisteSi apre subito nel drawer, senza conferma: è il tuo desktop
Link a un file, [report](docs/report.html)Testo normale, non si toccaDrawer, se il file è nella cartella della chat. Altrimenti resta testo
Link a un sito esternoFoglio del link, poi browser del telefonoUguale. Il tunnel raggiunge solo il desktop e la CSP non ammette altri frame
L'agente apre una paginaTutto schermo, anche mentre scriviDrawer a metà. Se stai scrivendo o l'avevi ridotto, non ti interrompe
Altro link con il drawer apertoNon si può toccare: la chat è copertaCambia pagina nello stesso drawer, Indietro riporta alla precedente
Desktop senza capacità previewFoglio del linkUguale

Il drawer non basta: limiti del tunnel ancora aperti

  • Il routing via Referer rompe le risorse annidate (dipendenze Vite, url() nei CSS) e i router SPA. Un dev server vero può apparire vuoto: serve un'origine per ogni porta.
  • Tutte le porte e le cartelle condividono un'origine: la pagina di una porta può leggere /f/<pty>/.env.
  • WebSocket e HMR non passano, quindi la pagina non si aggiorna da sola.
  • L'indirizzo non segue i link interni alla pagina.
  • Niente di tutto questo è mai stato provato su un telefono vero.

Cosa tocca nel codice

  • Instradamento unico dei link in browserUrl.ts, usato da onLink di ChatScreen e TerminalScreen.
  • useChatBrowser espone l'apertura di una pagina; WideShell la passa alla chat incorporata.
  • withLinks in ChatMarkdown rende toccabili i link a file.
  • AdaptiveSheet non basta: è modale e sa solo chiudersi. Nuovo BrowserDrawer con altezze, riusando le soglie di useSheetDrag.
  • L'errore di porta chiusa diventa una pagina HTML in preview.rs, oggi è testo semplice.

Da decidere

  • Quale variante.
  • Tablet: il drawer dal basso spreca la larghezza. Proposta: lì diventa un pannello a destra.
  • Prima il drawer, oppure prima un'origine per porta? Consiglio di farli insieme: un bel drawer con pagine vuote si noterebbe subito.
