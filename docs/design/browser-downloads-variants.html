Download nel browser in-app — conferma + menu download

Oggi il browser nativo (browser_view.rs on_download) accetta ogni download in silenzio. Proposta: ogni download chiede conferma, i file pericolosi (.exe .bat .msi .ps1 .cmd .scr .sh .apk…) hanno un avviso rosso, e c'è un elenco dei download dove vedere stato, aprire, mostrare nella cartella, ritentare, cancellare. Usa i pulsanti per vedere i vari stati.

Stato: Tema:

A · Barra sotto l'indirizzo + pulsante download consigliata

La conferma è una barra che spinge giù la pagina (niente overlay: la webview nativa resta viva e cliccabile). Compare un'icona download nell'header solo quando c'è almeno un download; anello di avanzamento mentre scarica. Il clic apre un popover in stile "schede".

Come funzionerebbe sotto (uguale per tutte le varianti)

  • La conferma non può bloccare WebView2: il callback on_download di wry è sincrono. Quindi il download parte subito ma in una cartella privata dell'app (…/flowcode/downloads-pending/, file .part). Con Scarica il file viene spostato in Download (nome libero, tipo file (1).zip); con Annulla viene cancellato. Così restano cookie/login del sito e nessun file arriva in Download senza consenso.
  • Avanzamento: wry dà solo "richiesto" e "finito", non i byte. La barra quindi è indeterminata (niente %); la dimensione si mostra se il server manda Content-Length (HEAD rapido) oppure a fine download.
  • File pericolosi: stessa lista che system.rs usa per non aprire eseguibili; per questi niente "Apri", solo "Mostra nella cartella".
  • Elenco: per finestra, persistito (ultimi 50), azioni: apri, mostra nella cartella, annulla, riprova, rimuovi dall'elenco, svuota. Se la conferma resta senza risposta, scade dopo 2 min e il .part si cancella.
  • Telefono: fuori scope per ora (il browser del telefono passa dal tunnel, i download lì sono un tema a parte).

Raccomandazione

A: la barra non copre la webview nativa (niente freeze-frame, puoi ancora leggere la pagina mentre decidi), il pulsante appare solo quando serve, e il popover riusa lo stile del selettore schede. "Non chiedere più per questo sito" (di C) si può aggiungere ad A come link nella barra.
