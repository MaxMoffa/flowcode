A · Lista evoluta

Stesso popup di oggi, più ricco. Ricorda il menu "puzzle" delle estensioni di Chrome.

  • In alto: le funzionalità già nella barra, come icone (con un punto se c'è un aggiornamento).
  • Righe: icona, nome, una riga di descrizione/autore, badge "Nuovo" / "Aggiornamento". Al passaggio: puntina + "⋯" (Gestisci, Disattiva, Disinstalla).
  • In fondo: Crea, Installa, Libreria.
  • + Cambio minimo, si usa come oggi.
  • − Con 30+ estensioni resta una lista lunga; scoprirne di nuove avviene fuori, nella libreria.

B · Griglia + Scopri

Un launcher stile "app": riquadri grandi, e un secondo segmento per sfogliare il catalogo senza uscire dal popup.

  • Installate: griglia 4 colonne per Agenti / Strumenti; puntina arancione = nella barra. Tasto destro su un riquadro = Gestisci / Puntina / Disattiva / Disinstalla.
  • Scopri: una in evidenza + popolari con "Installa" in un clic (passa comunque dalla conferma dei permessi).
  • Ricerca unica: trova sia quelle installate sia quelle del catalogo.
  • + Fa sembrare le funzionalità un ecosistema; installare diventa naturale.
  • − Più largo (420px); serve un catalogo online, che oggi non c'è.

C · Mini-libreria

Un pannellino a due colonne: categorie a sinistra, gestione rapida a destra. È un'anteprima della libreria dentro il popup.

  • Categorie: Tutte, Agenti, Strumenti, Create da me, Aggiornamenti, Scopri.
  • Righe: interruttore attiva/disattiva subito, puntina, "⋯". Disattivate restano visibili, sbiadite.
  • In fondo: "Chiedi all'agente di creare una funzionalità" (usa il tool MCP che crea plugin, con la card di consenso in chat).
  • + Gestione completa senza aprire la libreria; creare con l'agente diventa visibile.
  • − Il più grande (560×440); per "apri il Browser" è più pesante di oggi.
