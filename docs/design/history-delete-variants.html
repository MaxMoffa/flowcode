Eliminare chat dalla cronologia

Mock interattivi del pannello Cronologia (sidebar Agente). Ogni riga ottiene due azioni: Elimina e Mostra nel file manager. In più: svuota la cronologia del progetto. Prova a passare sopra le righe, click destro, eliminare e annullare. In fondo il piano di implementazione.

A · Pulsante ⋯ su hover + click destro → menuconsigliata

Riga invariata a riposo. Su hover compare ⋯ al posto del pallino; stesso menu con click destro (riusa ContextMenuContext). Eliminazione immediata + toast Annulla, niente dialog per la singola chat. Il ⋯ accanto alla ricerca apre il menu di pannello con «Svuota cronologia progetto…».

• Hover su riga → ⋯ · click destro = stesso menu
• «Elimina» → la riga si chiude, toast 6 s con Annulla
• Chat aperta in una scheda (pallino verde): «Elimina» disattivato, motivo nel menu
• OpenCode/Cline vivono in un database: «Mostra nel file manager» mostra il file .db (nota nel menu)
• ⋯ in alto a destra → «Svuota cronologia progetto…» → dialog con i conteggi
+ zero ingombro visivo, coerente con i menu esistenti (schede, scorciatoie)
− l'azione è "nascosta" finché non passi sopra
+ c'è spazio per altre voci (Copia ID, Rinomina in futuro)
+ funziona anche da tastiera (riga in focus → tasto Menu / Shift+F10)

B · Icone inline su hover + conferma nella riga

Su hover compaiono 📁 e 🗑 direttamente nella riga. Il cestino trasforma la riga in una conferma «Eliminare? Annulla / Elimina». Svuota progetto come in A.

• Hover → icone cartella e cestino
• Cestino → conferma dentro la riga (Esc annulla)
+ un click in meno per "Mostra nel file manager"
− le icone coprono il titolo, già stretto nella sidebar
+ conferma esplicita, nessun toast
− rischio click accidentale su 🗑 mentre si vuole aprire la chat

C · Modalità selezione (elimina più chat insieme)

Pulsante «Seleziona» nel footer: le icone diventano checkbox, barra in basso «Elimina N». Utile per pulizie mirate; si può aggiungere sopra ad A in un secondo momento.

• «Seleziona» → spunta le righe → «Elimina N»
• «Tutte» seleziona quelle visibili (rispetta la ricerca)
+ copre il caso "ne voglio togliere 10 ma non tutte"
− un modo in più da imparare; per la singola chat è più lento di A

2 · Backend (Rust, nuovo src-tauri/src/agents/history_delete.rs)

  • history_locate(cli, sessionId, profile, wslDistro) → path: per «Mostra nel file manager», poi frontend chiama revealItemInDir (già usato da ImageFileViewer).
  • history_delete(items[]) → {deleted, skipped[]}: per i file → Cestino di sistema (crate trash, nuova dipendenza) così resta recuperabile anche dopo il toast; per i DB → transazione SQLite. Restituisce un undoToken.
  • history_undo(undoToken): file → ripristino dalla posizione originale (copia tenuta in appData/history-trash/ per 1 min, poi solo Cestino); OpenCode → time_archived = NULL; Cline → reinserimento righe salvate.
  • history_delete_project(roots[], wslDistro, includeDelegates): ri-usa gli stessi scan dell'elenco, filtra per progetto, salta le chat aperte in una scheda o vive (lock Codex, live_session_in OpenCode, sessioni attive Claude).
  • Sicurezza: il path viene sempre ricostruito dal backend da cli + id, mai preso dal frontend; si rifiuta tutto ciò che non sta sotto la home dell'agente (niente path traversal).
  • Dopo l'eliminazione: invalidare le cache (wsl_codex_sessions_cached, delegate history) ed emettere evento così historyStore rilegge subito.

3 · Frontend

  • AgentHistoryPanel.tsx: pulsante ⋯ nella riga (al posto del pallino su hover) + onContextMenu → openMenu con voci Apri / Mostra nel file manager / Copia ID / Elimina (danger, disabled se row.tabId).
  • Rimozione ottimistica in historyStore (set di chiavi "nascoste") → la riga si chiude subito; se il backend fallisce torna + toast errore.
  • Toast «Chat eliminata · Annulla» (6 s) in basso nel pannello; più eliminazioni di fila = un solo toast "3 chat eliminate".
  • Kebab accanto alla ricerca → «Svuota cronologia progetto…» → dialog con conteggi per agente, chat aperte escluse, opzione delegate; pulsante rosso «Elimina N chat».
  • Delegate: eliminare un orchestratore chiede se includere i suoi figli (checkbox nel toast/dialog), default sì.
  • i18n: chiavi history.menu.*, history.delete.*, history.clear.* in tutte le lingue in src/i18n/locales.

4 · Telefono / PC remoto (fase 2)

  • Nuovo comando in remote/dispatch.rs accanto a run_history; pressione lunga sulla riga nel telefono → sheet con «Elimina» (niente «Mostra nel file manager» sul telefono).
  • RemoteHistoryPanel.tsx (PC→PC): stesso menu di A, «Mostra nel file manager» disattivato (file sull'altro PC).

5 · Test

  • Rust: unit test per ogni agente su home temporanea (file → finiscono via, DB → archiviati/rimossi, undo li riporta, chat viva saltata, path fuori home rifiutato).
  • Vitest: rimozione ottimistica + rollback su errore in historyStore; filtro progetto per «svuota».
