Pannello Agente — dove metterlo

Oggi il pannello Agente (contesto, utilizzo, delegati — AgentInsightPanel) è il terzo tab dello switch della sidebar, accanto a Cronologia ed Esplora. Problema: per vederlo devi lasciare file o cronologia, e Cronologia/Esplora/Agente sono cose di natura diversa (navigazione vs stato della sessione). Qui 4 alternative + lo stato attuale. I mock sono cliccabili.

⎇ master4

Ora: terzo tab della sidebar

  • Tanto spazio verticale, nessun overlay.
  • Esclusivo: guardi il contesto oppure i file / la cronologia.
  • Mescola navigazione (file, sessioni) con lo stato della sessione attiva.
  • Lo switch a 3 voci è stretto; scompare/compare in base al tab attivo (terminale semplice = solo Esplora).
  • Il % di contesto non si vede finché non apri il tab.

A · Dock Agente in fondo alla sidebar

Lo switch torna a 2 voci. In fondo alla sidebar, sotto qualunque tab, una riga fissa con barra del contesto e %. Clic → si apre verso l'alto come il dock Git (ridimensionabile, stato salvato).

  • % sempre visibile, anche mentre navighi file o cronologia.
  • Stesso pattern già usato da GitDock: niente di nuovo da imparare.
  • In Esplora ci sono due dock impilati (Git + Agente): fondo affollato.
  • Aperto ruba altezza all'albero file.
Clicca la riga "Agente" in basso.

B · Anello di contesto nell'header della chat

La sidebar torna solo navigazione (Cronologia / Esplora). Nell'header della chat — vicino al selettore progetto — una pillola con anello + %. Clic (o Ctrl+Shift+A) → popover con il pannello completo.

  • Il dato sta dove sta la sessione a cui si riferisce.
  • % sempre visibile senza occupare la sidebar; l'anello diventa giallo oltre la soglia.
  • Sidebar più semplice: lo switch non cambia più forma tra tab agente e terminale.
  • Overlay: chiude se clicchi fuori (opzione "Fissa in sidebar" per chi lo vuole fisso).
  • Nei tab terminale serve un header equivalente (pillola nella tab strip o barra sottile sopra il terminale).
Clicca la pillola "42%" in alto a destra.

C · Barra icone verticale (stile VS Code)

Lo switch segmentato diventa una colonna di icone a sinistra. L'icona Agente ha un anello di contesto intorno; Esplora ha il badge delle modifiche Git. Clic sull'icona attiva → chiude la sidebar.

  • Scala bene: altre sezioni future (plugin, ricerca…) senza stringere lo switch.
  • % leggibile a colpo d'occhio dall'anello anche con la sidebar chiusa.
  • Resta esclusivo come oggi (Agente o file).
  • Cambio di layout più grosso: 46 px fissi in più, icona panel-left attuale da ripensare.
Clicca le icone a sinistra.

D · Scheda sessione in cima alla Cronologia

Il tab Cronologia diventa Sessione: in cima una scheda della sessione attiva (titolo, barra contesto, Compatta) con chip Contesto / Utilizzo / Delegati che si espandono inline; sotto, la cronologia come oggi.

  • Raggruppa ciò che riguarda le sessioni: quella attiva + le passate.
  • Switch a 2 voci, niente overlay.
  • Esplora resta separato: il % non si vede mentre navighi i file.
  • Espansa, la scheda spinge giù la cronologia.
Clicca i chip nella scheda.
