Pagina File al posto di Terminali

La seconda scheda diventa un esploratore di file del computer, da cui aprire una cartella in un terminale o in un agente. I terminali semplici si spostano nella home, accanto agli agenti. Ogni variante propone sia la pagina File sia la home: i telefoni qui sotto funzionano davvero.

Valido per tutte le varianti

Il telefono oggi legge soltanto, e solo dentro la cartella di un terminale aperto. Il grosso del lavoro è qui, non nell'interfaccia.

Sul telefono

  • Scheda terminals sostituita da files in App.tsx; etichetta "File" già tradotta.
  • sessionsOf oggi scarta le shell: la home deve riceverle a parte, senza stato perché il PC non ne manda.
  • Il pulsante "Nuovo" di Terminali deve restare raggiungibile dalla home, anche senza terminali aperti.
  • useOpenNew, PendingRow e BusyArc escono da Terminals.tsx, perché la home li usa.
  • Si perde il raggruppamento per finestra del PC: tenerlo solo se usi più finestre.
  • Il tablet resta com'è: ha già il suo pannello file in WideFiles.

Sul computer (nuovo)

  • ls e read vogliono un ptyId: serve navigare senza terminali aperti, partendo da radici date dal PC (utente, dischi, WSL).
  • Nuove operazioni: crea, rinomina, sposta, elimina, salva. Una nuova capability nasconde tutto ai PC vecchi.
  • Il salvataggio deve rifiutare un file cambiato sul PC dopo la lettura, altrimenti sovrascrive il lavoro di un agente.
  • read taglia a 1 MB: un file tagliato non deve mai essere salvabile, si perderebbe il resto.
  • Eliminare manda al Cestino di Windows. In WSL il Cestino non c'è: serve una scelta a parte.
  • Sicurezza: il telefono abbina già shell complete, quindi il rischio non cresce, ma cade la vecchia regola "solo nella cartella del terminale". Va rivista in fsbrowse.rs.
