Git dentro Esplora + "Agente" al posto della tab Git

Mockup interattivo con dati finti. Oggi: sidebar con tab Cronologia · Esplora · Git, e pannello Agente (Contesto / Consumi / Delegati) aperto a destra. Proposta: Git diventa una sezione richiudibile dentro Esplora, come in VS Code, e la tab liberata ospita Agente. Clicca le intestazioni delle sezioni per chiuderle o aprirle, trascina il bordo tra due sezioni aperte, usa i bottoni sotto le note per provare una tab normale (senza agente).

Ha senso? Sì, con una condizione. Git e l'albero dei file parlano della stessa cosa (i file del progetto), quindi stare insieme ha senso: in più l'albero può colorare i file modificati come fa VS Code, e il contatore delle modifiche resta sempre visibile nell'intestazione. Spostare Agente a sinistra libera la colonna di destra per il browser, che oggi deve dividersi lo spazio con Agente (è proprio il caso che l'ultimo commit sul layout ha dovuto gestire).
Il costo: non vedi più Agente e i file nello stesso momento, e per le tab senza agente la tab Agente sarebbe vuota. Per questo nelle varianti A e B la tab Agente compare solo quando la tab attiva ha un agente, esattamente come oggi fa Cronologia.
Preferita: B con cassetto ridimensionabile: barra del repo sempre visibile, albero a piena altezza finché non apri Git, altezza del cassetto decisa da te (doppio clic sul bordo = tutta altezza). A resta l'alternativa più vicina a VS Code; C non libera la colonna di destra, quindi risolve solo metà del problema.
