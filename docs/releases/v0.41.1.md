## 🧹 Tidy history, steadier links

Spring cleaning came early to the pond. The History panel now lets you throw away the chats you no longer need — one at a time with a quick Undo, or a whole project in one go — and find any chat's file on disk with a click. Working from a second PC got another round of polish, terminals on Linux finally pick a proper monospace font, and the brave can try ACP v2 behind a new Experimental switch. The frog swept its lily pad and found three flies under it. 🐸

### ✨ New features

- **Delete chats from the History.** Hover a chat and click **⋯**, or right-click it: Resume, Show in file manager, Copy session ID and Delete. Deleting hides the chat at once and gives you a few seconds to Undo before it is removed for good, together with the chats it delegated. Chats open in a tab are never touched.
- **Clear a project's history.** The **⋯** next to the search box clears every saved chat of the project, with a confirmation that tells you how many chats of each agent are going away.
- **Show in file manager.** Jump straight to a chat's transcript (Claude, Codex), session folder (Vibe, Cline) or database (OpenCode).
- **ACP v2, experimental.** A new Experimental section in Settings turns on the next version of the agent protocol: native subagent sessions, exact background work tracking, and delegated chats that inherit it. The agent popover shows when it's on.

### 🛠 Improvements

- **Another PC, smoother.** The link between two computers is sturdier, chats and terminals stay in sync, the remote terminal sizes itself to its box, local tabs switch back to this PC, and a new tab typed while another PC is in front opens on that PC.
- **Codex notices.** Codex warnings show up once as a notice card instead of repeating in the chat.
- **Links in terminals.** Right-clicking a link in a terminal opens the link menu.
- **Linux terminals.** Real monospace fallbacks instead of fonts that don't exist there; the new tab page uses the terminal font too.

### 🐛 Bug fixes

- **Linux browser.** The native browser page sits inside its card again instead of below the interface.
- **OpenCode sign-in on macOS.** A sturdier check after browser login, so it no longer reports "Sign-in incomplete" by mistake.
