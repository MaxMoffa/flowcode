## 🪞 One look, any PC

The pond got a mirror. Working on another computer now feels exactly like working on this one: the same History, the same file explorer, the same editor tabs and the same new-tab page, all reading from the other PC. The built-in browser also learned some manners — menus and dropdowns open over a live page instead of freezing it — and you can finally give your chats proper names. The frog looked into the water and saw two frogs. Both of them waved. 🐸

### ✨ New features

- **Rename chats.** Pick **Rename** in a chat's History menu and type a new title right in the row: Enter saves, Escape cancels, an empty name brings back the agent's own title. Works for every agent, and the History search finds the new names.
- **Another PC's files in editor tabs.** Files of the other PC open in the same editor as local ones, as real tabs you can edit and save, with conflict checks and your unsaved text kept when you switch away.
- **The full explorer on another PC.** Create, rename, delete, search, duplicate, file info, favorites and "open in terminal" on the other PC's files, with the same menus as on this one.
- **The real new-tab page on another PC.** The **+** on a remote PC opens the familiar new-tab page: that PC's folders, profiles, shells, typed commands, folder search and system banner, with only the agents signed in there.
- **Delete chats on another PC.** The History of a remote PC gets Delete with Undo and "Clear project history…", like the local one.
- **Menus over a live page.** Right-click menus and dropdowns now open over the browser without freezing the page behind them (Windows; context menus also on macOS).

### 🛠 Improvements

- **A tidier Features menu.** One-line rows, the usage gauge right on the row, and a **‹** button that opens a plugin's usage popover beside the menu and keeps it open.
- **Clearer shortcut reordering.** Hold a shortcut in the header bar and a ring fills up; then it lifts, follows the pointer and the others slide aside to show where it lands.
- **Phone browser and dev servers.** The phone now reaches the desktop's dev servers through a real loopback tunnel, so hot reload, WebSockets, workers and client-side routes just work.
- **Crash reports on Linux and macOS.** Native crashes there now leave evidence and open the crash report dialog, like on Windows.
- **Softer composer.** The idle chat composer loses its thin ring, and the selected Chat/Terminal pill is flat.

### 🐛 Bug fixes

- **macOS browser crash.** The app no longer crashes when a browser page has no address yet.
- **Linux browser.** Menus and dialogs over a page show a still picture of it instead of a "page paused" hole.
- **OpenCode sign-in.** Signing in to OpenCode no longer freezes at its first prompt, and the sign-in button in the Features menu works again.
- **Remote History search.** The search bar of a remote PC's History has the right size.
