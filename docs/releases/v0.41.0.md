## 💌 Agents talk, computers team up

Your agents can finally pass notes. An agent in one tab can now write to an agent in another tab, whoever they are — Claude asking Codex to check its API, Gemini handing a finding to OpenCode — and you stay in charge: by default every incoming message waits for your OK. Working with a second PC feels like working with this one: its chats, terminals, Git, browser tabs and Agent panel all show up as if they were local. Under the hood we went through the whole app with a fine-toothed comb: panels and cards now open and close smoothly instead of jumping, long chats stream lighter, and a batch of bugs and security gaps are gone. The frog has started a pen pal club. 🐸

### ✨ New features

- **Messages between agents.** Agents in different tabs can message each other through Flowcode, whatever the agent: `send_message`, `wait_for_reply` and `read_messages`, and `list_agents` shows which tabs accept messages. A message reaches a chat as a card and runs a turn once you accept it; terminal tabs get a notice with Copy and Insert buttons.
- **You decide who gets mail.** Each tab accepts messages always, after asking (the default) or never, from its right-click menu; "Always from this tab" remembers a trusted sender. Consent cards also show up on the phone.
- **Another PC, like this one.** On a linked computer you can now start new chats and use `/clear`, pick the folder of a new tab, attach files, answer and open delegated tasks, manage `/goal`, see `call_user`, permission and question bubbles, open path and web links from its terminals, and use its Git drawer, Agent tab, Agent panel and side panel.
- **The other PC's browser here.** Its browser tabs are mirrored in this Browser panel, its pages open through a tunnel, and its files open in a read-only viewer. The header's PC selector is a single pill that only shows up when there is more than one computer.
- **Readable browser errors.** When a page can't load, the technical details now explain the error in plain words, with the HTTP status when the server answered.

### 🛠 Improvements

- **Smooth panels and cards.** Side panels slide instead of stretching the chat or terminal next to them on every frame, terminals refit once at the end, and the browser page waits for the slide to finish. Permission, question, cache, terminal and subagent cards now animate out instead of vanishing, without the chat jumping.
- **Lighter while agents work.** Hidden chats update less often, open chats no longer redraw when something else changes, streamed answers re-read only their last part, and the in-app browser no longer measures the whole window on every change.
- **Agents that start working on their own now look busy.** When an agent picks up a message from another session or a background task by itself, the tab animates and the busy row with the frog appears, as for any turn — and you can still write to it meanwhile.
- **Delegated tasks follow your permissions.** A delegated agent now starts with the same permission strictness as the chat that asked for it, never looser.
- **Phone polish.** The browser drawer slides on the GPU and closes cleanly, long folders show the first 300 entries with "show more", the reconnect screen goes quiet after a few seconds, and the widgets are kinder to the battery.
- **Contributing guide.** The repository now has a CONTRIBUTING guide and templates for pull requests and issues.

### 🐛 Bug fixes

- **Localhost pages stuck on an error.** Reopening a page that had failed (from a link or an agent) showed the old error again without retrying; it now loads it again. Addresses like `127.0.1.1` count as local too.
- **Links in inline code.** Addresses an agent writes as `code` in chat, like `http://localhost:5173/`, are clickable.
- **Processes left behind.** Servers and daemons an agent started are stopped when the agent exits on its own, and quitting Flowcode no longer takes many seconds with several chats open.
- **Security hardening.** Browser tools are auto-approved only with their own arguments, phone tunnels block debugging and local AI ports and refuse pages reaching other ports, and network-share folders are refused when resuming from the phone.
- **Profile copy crash.** Copying settings into a new profile no longer crashes on a folder link that loops back on itself.
- **Dictation.** Stop now works while the speech model is still loading, and a corrupt model download is caught early.
- **Terminals.** Right-click opens only Flowcode's menu when an app captures the mouse, and full-screen apps no longer get their screen cleared.
- **Sign-in on macOS and Linux.** Browser sign-in for agents runs in your login shell, Codex usage never opens its interactive screen when signed out, and Cline's sign-in, status and usage follow chats into WSL.
- **Linux.** The window paints again on systems where it stayed see-through.
- **Smaller fixes.** OpenCode respects custom XDG folders, a queued message for another PC keeps its files, and the browser's tab drawer and actions menu no longer get squashed.
