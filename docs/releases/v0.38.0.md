## 🪷 Agents everywhere, chats in a blink

The pond got busier and faster at the same time. Agents you start in a plain terminal tab now get the same Flowcode superpowers as chats: they can open pages, call you, and hand work to other agents. Long chats open almost instantly, showing the latest turns first and loading older ones as you scroll. Web pages in the browser panel now run in a real native webview. And if Flowcode ever crashes, one of your own agents can investigate before you report it, so you find out whether it's your machine or our bug. The frog learned to leap between lily pads. 🐸

### ✨ New features

- **Crash analysis with your agents.** The crash dialog gains an "Analyze with…" button. A read-only diagnosis chat checks logs, drivers and your system, then attaches a verdict to the report: a problem on your PC (with steps to fix it), a likely Flowcode bug (with evidence and steps to reproduce), or an issue someone already reported. The report on GitHub gets much clearer.
- **Flowcode tools in terminal tabs.** Claude, Codex and OpenCode started in a terminal tab, from the launcher or typed by hand, can open pages in Flowcode's browser and send you a bubble, on Windows and in WSL.
- **Delegation from terminal tabs.** Agents in a terminal can delegate tasks to other agents too: the tab shows a card with its delegates and opens each child as a chat tab next to it. The phone sees them as well.
- **Native browser for web pages.** URL pages in the browser panel run in a native webview instead of an iframe, with a freeze frame while menus cover it and a new ⋯ menu.
- **Context pill in the agent header.** The agent panel now opens from a small pill (fill ring and %) in the chat and terminal-agent headers. Ctrl+Shift+A toggles it, and "Pin to sidebar" brings back the old sidebar tab.

### 🛠 Improvements

- **Chats open in a blink.** Only the latest turns load at first, older ones follow as you scroll up. A resumed chat shows its saved preview while the agent starts, and very long chats render only what's near the screen.
- **Faster History.** Each agent's sessions appear as soon as they're found, with ghost rows instead of an empty list. Returning to the tab is instant, and big histories (especially Claude and WSL ones) scan much faster.
- **Paged history on the phone and remote desktops.** The phone gets the tail of a chat first and loads older pages on scroll-up.
- **Reliable agent detection in terminal tabs.** Every agent is recognized the same way on Windows, WSL, macOS and Linux, including agents started through Git Bash or launchers that exit. A new "Agent detection diagnostics" item in the tab menu helps when one isn't recognized.
- **Quicker Codex chats in WSL.** The Codex check is cached instead of running every time a chat opens.
- **Release covers.** Every release now has an 8-bit cover, shown on top of its notes in the Changelog and What's new pages.
- **A new website.** The Flowcode site was rebuilt from scratch, with a live, clickable Flowcode window on the home page and one page per release.

### 🐛 Bug fixes

- **No more popping console windows.** Background helpers left behind by some agents (Cline, Codex) could open visible terminal windows after their tab closed. Each tab now ends its whole process tree.
- **macOS:** the window background is properly blurred, and Codex started in a tab is no longer stuck being shown as "zsh".
