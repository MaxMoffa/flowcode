## 🧹 Tidy tabs, quick reconnects

A small spring clean for the browser and a faster phone. Too many tabs open? The tab list is now a drawer where you can filter them and close a whole batch at once, and if you swept away one too many, Undo brings them back. On the phone, the link to your computer comes back much faster after the screen wakes or the network changes, and while it does you see a calm loading screen instead of a sheet popping up. We also fixed the context percentage for Claude chats, which looked five times fuller than it was. The frog swept the lily pad clean. 🐸

### ✨ New features

- **Browser tabs drawer.** The browser tab list opens as a drawer on the right, with filter chips and a menu to close other tabs, tabs to the right, agent tabs, files or everything at once.
- **Undo after closing tabs.** A toast after a bulk close reopens the closed addresses with one tap.
- **Bulk close on the phone.** The phone's tabs popover has the same bulk actions, with undo for web addresses.
- **Phone connection screen.** When the link to the computer is down, Home and Files show a full screen with the steps, a retry button, another computer to pick and the details, and the bottom bar slides away until the link is back.

### 🛠 Improvements

- **Faster first reconnect on the phone.** The phone tells the network layer about changes before every attempt, gives up a stuck first attempt after 6 seconds instead of 12, rebuilds the connection after two failures and no longer restarts an attempt that has just begun when the app resumes.
- **Calmer phone loading.** Home shows a plain skeleton until the first lists arrive. The reconnect sheet is gone; terminals, Settings and the wide layout keep a small pill.

### 🐛 Bug fixes

- **Context percentage too high for Claude.** The context panel assumed a 200K window for every Claude model, so 1M sessions showed five times the real use. Chats now use the window the agent reports, or the right one for the model; OpenCode and Cline follow the same estimate for Claude models.
