All files are on the GitHub Releases page. Pick the one matching your system.

Install

  1. Go to the Releases page.
  2. Download the installer for your system.
  3. Run it and follow the steps. If Flowcode is already installed, the installer offers to update it, keeping your settings.

On first launch a short tour shows you the main features and lets you pick a theme.

After installing

  • Flowcode updates itself in one click, verified against signed checksums.
  • Want the phone app? Pair your phone.
  • Curious about the agents? Meet them.
  • Open source under Apache 2.0. Source on GitHub.
