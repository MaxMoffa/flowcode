The philosophy

The terminal is the center, everything else revolves around it

Terminal, file manager, editor, a browser to check your usage limits: four windows, and the thread lost every time you switch. Flowcode brings them into one.

  • One folder, one context

    The file explorer and the editor follow the active terminal's folder, even inside WSL. You cd, and the rest of the app comes along.

  • AI agents feel at home

    Claude Code, Codex CLI and Mistral Vibe are recognized, shown in a dedicated panel, with how much usage you have left (or, for Mistral Vibe, how much you've spent).

  • Light and native

    Built on Tauri, not Electron: it installs in a moment, starts instantly and uses little memory.

  • Extensible without risk

    Plugins are declarative JSON files, not code: install a colleague's plugin without worrying about what it runs.

  • Pick up where you left off

    Tabs, folders and output come back when you reopen the app, and your settings survive updates.

Features

What you can do

  • 🗂️

    Tabbed terminal

    Several sessions side by side, draggable between windows, grouped automatically when they don't fit the bar. Per-tab text zoom.

  • 📁

    Side file explorer

    Browse, search recursively and manage the files of the active folder. Favorites for the folders you use most.

  • ✏️

    Built-in editor

    Open and edit files on the fly, with syntax highlighting and a symbol outline.

  • 🤖

    Agents panel

    See every open Claude Code, Codex CLI and Mistral Vibe session, resume it in one click and watch your remaining usage. Launch agents from the panel, optionally in their own git worktree.

  • 👤

    Account profiles

    Several accounts for Claude Code, Codex and Mistral Vibe, with a profile selector in each agent's popup.

  • ⏯️

    Auto-resume

    When an agent hits a usage limit, Flowcode can resume it on its own once the limit resets.

  • 🌿

    Git panel

    Stage files, commit, review diffs and switch branches without leaving the app.

  • 📱

    Android companion app

    Follow and answer your agents, open the PC's terminals and get notifications from your phone.

  • ⚡

    Features and shortcuts

    A customizable quick-action bar: commands, status popups, shortcuts to your own tools.

  • 🐧

    Your shell of choice

    PowerShell, cmd, bash, zsh, WSL… pick the default one for new tabs.

  • 🎨

    Light, dark and automatic themes

    Frosted-glass panels with adjustable opacity. The layout also adapts to narrow, phone-like windows.

  • 🌐

    Multilingual

    English and Italian, following your system language by default.

  • 🔄

    In-app updates

    Flowcode checks for new versions on startup and updates itself in one click, verifying signed checksums first.

Phone app

Android companion app

Control your desktop's agents and terminals from your phone. There's no account to create and no VPN to set up.

What you can do

  • Follow your agents and their usage limits, per profile.
  • Reply to agent prompts straight from the phone.
  • Open the PC's terminals and type into them.
  • Browse the PC's files.
  • Run quick actions from the shortcuts bar.
  • Mirror the desktop's settings.
  • Opt-in background mode, with notifications when an agent needs you.
  • Biometric lock for the app.

How it connects

The phone and the PC talk through iroh: the connection is end-to-end encrypted and peer-to-peer, with a relay as fallback when a direct path isn't possible.

Remote access is off by default, and a paired device can be revoked at any time from the same settings page. Note that a paired device can type into your terminals.

Pair in three steps

  1. Install Flowcode-Android-<version>.apk on your phone, allowing unknown sources if Android asks.
  2. On the PC, open Settings → Agents and turn on Allow access from the Flowcode phone app: a QR code appears.
  3. In the app tap Add computer and scan the code.

Install

Up and running in a minute

  1. Go to the Releases page.
  2. Download the installer for your system.
  3. Run it and follow the steps. If Flowcode is already installed, the installer offers to update it, keeping your settings.

On first launch a short tour shows you the main features and lets you pick a theme.
