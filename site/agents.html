02

Chat modeNew

Talk to any agent in a real chat, not just in a terminal. Try it on the home page.

  • Images & attachments

    Paste screenshots; send files from the phone.

  • Math, mermaid, tables

    KaTeX, diagrams and expandable tables.

  • Questions in the composer

    When the agent asks, you answer right where you type.

  • /goal

    A chip tracks the goal; a marker when it’s reached.

  • The pond

    The frog sinks when a session ends, waits on a pad at a limit.

  • Auto-resume

    Queued messages resume when the limit resets.

03

DelegationNew

One agent hands a task to another through the Flowcode MCP server. The planner plans, the builder builds, and you stay in the loop.

  • Agent panel

    Every session at a glance, resume in one click, launch in its own git worktree.

  • Profiles

    Several accounts per agent, each with its own login and usage gauge.

  • Auto-resume

    Hit a usage limit? The chat resumes by itself when the limit resets.
